# Raghv-m GitHub profile refresh

## Install
1. Download and extract this package.
2. Open your existing `raghv-m/raghv-m` profile repository.
3. Back up the current README.md.
4. Copy this package's README.md and `assets/` folder into the repository root.
5. Commit and push. The profile README must be in the public repository named exactly `raghv-m`.

## Important accuracy checks
- `assets/nait-mark.svg` is a custom typographic NAIT-inspired mark, not an official NAIT logo file. Replace it with an approved official logo asset if you have one or can obtain one from NAIT brand resources.
- Confirm the project names and descriptions in the README and projects.svg before publishing. Remove any project that is not public or not ready to showcase.
- GitHub README does not execute JavaScript or CSS. These animations are SVG-native and may be rendered differently by GitHub clients.
- External stats images depend on third-party services and may occasionally be unavailable. The profile remains readable without them.
- The README uses your public portfolio URL: https://www.raghv.dev

## Preview locally
Open `README.md` in VS Code or preview it on a temporary branch before merging.
